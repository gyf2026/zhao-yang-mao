# 关注清单（deal-hunter 每轮必查）

> 每个条目一个小节。字段说明：
> - 主词：每轮必搜；辅词：每轮轮换 2-3 个，控耗时
> - 目标价：低于此价（含券后）直接算命中，不要求满足通用门槛的"≥100 元/≥50%"
> - 排除：标题含这些词的结果丢弃（如配件、二手、试用装）
> - 命中范围：好价 / 优惠券 / 免费试用 / 保障卡与权益活动

## 动态血糖仪（CGM）
- 主词：动态血糖仪
- 辅词：瞬感、雅培瞬感、三诺动态、硅基动感、微泰、CGM
- 目标价：未设（沿用通用门槛：单套省额 ≥100 元即命中）
- 排除：试纸、采血针、血糖仪（非动态）
- 命中范围：好价 / 优惠券 / 免费试用 / 保障卡与权益活动
- 备注：单套动辄数百元，重点盯"新低"标注与大额券
