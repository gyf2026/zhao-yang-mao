# 站点手册：每个站怎么用、抓什么、坑在哪

> 实测环境：macOS + 真 Chrome（CDP 直控）。国内站直连，境外站走本地代理。
> 标注「实测」= 亲自打开并读到了内容；标「未验证」= 听说过但没测，第一次用先小范围试。

**通用心法：先便宜的、再贵的。**
直连脚本能拿到 → 绝不开浏览器；浏览器能拿到 → 绝不点进 App。
每多一层，就多一层出错的可能。

## 一、什么值得买（smzdm）

| 项 | 内容 |
|---|---|
| 入口 | **全部好价 `https://faxian.smzdm.com/`（主力）**；精选 `https://www.smzdm.com/jingxuan/`；搜索 `https://search.smzdm.com/?c=home&s=<关键词>&order=time` |
| 通道 | 列表 → 直连脚本 `scripts/smzdm_feed.py`（faxian 优先）；**搜索 → 必须真浏览器**；详情页被验证码拦时也转浏览器 |
| 登录 | 可选。不登录能搜能看，登录后结果更稳、能看到更多评论 |

### 频道地图：精选不是全量

站内有五个互不相同的入口，**只扫精选会漏掉一大半**。2026-11-01 同一时刻对比：精选 72 条，首页 68 条里 44 条不在精选内；排行榜 56/72 不在精选内；商城页、海淘页的条目 100% 不在精选内。

| 频道 | 地址 | 结构特征 | 定位 |
|---|---|---|---|
| **全部好价** | `faxian.smzdm.com/` | `feed-block-ver`，默认 `data-tab="最新"`，带「优惠精选 / 小值爆料 / 百亿补贴」角标 | **每轮主力** |
| 全部好价·翻页 | `faxian.smzdm.com/p2/` | 同结构 | 第 2 页起 |
| 全部好价·品类 | `faxian.smzdm.com/h1s0t0f<品类ID>c0p<页码>/` | 同结构 | 定向盯品类 |
| 精选好价 | `www.smzdm.com/jingxuan/` | `feed-block z-hor-feed`，字段在内嵌 `sensors.track` 里，**有值/不值票数** | 质量旁证（票数只在这里有） |
| 白菜 9.9 | `faxian.smzdm.com/9kuai9/` | 同 faxian | 低价小件，默认不推 |
| 优惠券 | `duihuan.smzdm.com/quan/` | 券卡片列表 | B 类羊毛，多数券要登录 |
| 排行榜 | `www.smzdm.com/top/` | 商品榜 | 查常卖价参考，**不是时效好价** |
| 海淘 | `haitao.smzdm.com` | 海淘精选 / 限免 | 0 元 App 限免在这里出过 |
| 商城页 | `www.smzdm.com/mall/<商城>/` | 店铺聚合 | 商城专属券，补漏 |

品类 ID：`python3 scripts/smzdm_feed.py --channels` 可直接打印（电脑数码 163、食品生鲜 95、日用百货 1515、家用电器 27、手机 165…）。

**两种列表结构的区别（决定解析器）**：faxian 用 `div.feed-block-ver` + `h5.feed-ver-title` + `div.z-highlight`，没有票数、有角标；精选用 `div.feed-block z-hor-feed` + 内嵌 `sensors.track('FeedArticleClick',{...})`，有票数、无角标。脚本按页面里是否含 `feed-block-ver` 自动切换。

**建议操作**

1. 先抓全部好价：`python3 scripts/smzdm_feed.py --channel all --page 1 --save <快照路径>`，一页约 20 条；需要更多就 `--page 2`。
2. 关注清单里的品类，用浏览器开搜索页，**一定带 `&order=time` 按时间排序**，否则默认综合排序会把几天前的老帖顶到前面。
3. 每个关键词最多翻 1 页。辅词每轮轮换 2–3 个，别一次全跑完。
4. 候选进推送前，先跑 `--detail` 查过期，再开商城原链接核价核库存。

**详情页被拦时的浏览器核验（跑这一段）**

```bash
python3 scripts/browser.py open "https://www.smzdm.com/p/185236762/" --session deal-hunter  # 开新标签，不抢已有页
python3 scripts/browser.py list --session deal-hunter                                      # 取 targetId
python3 scripts/browser.py eval --session deal-hunter "document.title"                     # 标题里带 "【省X元】"
python3 scripts/browser.py eval --session deal-hunter 'document.body.innerText.replace(/\n+/g," / ").slice(0,400)'
# 页面里有多个标签时用 --target <id> 指定，否则默认取第一个 page
```

正文里同时能看到：更新时间（`更新时间：23:10`）、值/不值票数、优惠构成（立减/满减券/淘金币）、爆料原文。
**看到"来晚了~优惠已错过"就是过期**，直接丢。拿不到正文就当未核验，不许推。

**抓什么**

- 标题、现价（含"需买3件，需用券"这类括号条件）、商城、值/不值票数
- 历史低价标注原文——这是判定门槛 b/c 的唯一依据，必须原样记录
- 是否需凑单/领券：看价格文本里的括号，以及正文里的"满X减Y"

**坑（都踩过）**

- **搜索页直连拿不到**：`search.smzdm.com` 对 curl 返回 202 + `probe.js` 挑战页，正文是空的。看到 202 就别再试直连了，直接上浏览器。
- **验证码会伪装成成功**：抓太勤时 `www.smzdm.com` 返回腾讯 TCaptcha 页，HTTP 200、约 1.7KB，`<title>` 为空。这时旧逻辑会判 `expired=false` 放行，等于把没核验过的当已核验。脚本现在抛 `Blocked`（退出码 2）。**注意 `faxian` 与 `www` 是分开拦的**，一个被拦另一个往往还能用。
- **过期判定有假信号**：详情页里每个帖子都藏着一段"无货或下架"的隐藏报错模板，拿它当过期依据会全部误杀。真标记是 `card-bottom-overdue` + 文案"来晚了~优惠已错过"。
- **跳转链接不是商品链接**：站点内的 `go.smzdm.com/xxx` 是跳转，核价要点进去到商城真实页面，否则看不到实时价和库存。
- **改版会让解析归零**：脚本返回 0 条就是改版了，别硬跑，改走浏览器并提示更新脚本。
- 评论数列表页并非每条都有，缺就写未知，别拿 0 冒充。

## 二、慢慢买（比价 / 历史价）

| 项 | 内容 |
|---|---|
| 入口 | `https://www.manmanbuy.com/`；商品历史价页可从站内搜索进入 |
| 通道 | 浏览器（首页也能直连，但历史价曲线要 JS 渲染） |
| 登录 | 一般不强制；部分深度功能要登录或 App |

**建议操作**

- 只用来干一件事：**印证"历史低价"是真的**。smzdm 标了"新低"，到这里看曲线是否真的在地板上。
- 输入商品链接比输入关键词准。复制京东/淘宝商品链接查，比搜标题靠谱。
- 曲线图和"历史最低价"文字都在 DOM 里，直接读文本比截图省事。

**坑**

- 首页 `<title>` 为空（编码问题），别拿标题判断页面是否加载成功，要读正文长度。
- 全网比价对同一商品的不同 SKU 会混在一起（颜色/容量不同价不同），结论要带一句"口径可能不齐"。
- 反爬比 smzdm 严，短时间高频查询会被要求验证。

## 三、赚客吧（zuanke8）/ 0818 团

| 项 | 内容 |
|---|---|
| 入口 | `http://www.zuanke8.com/`、`http://www.0818tuan.com/` |
| 通道 | 浏览器；也可以用 curl 直连（同样必须 `http://`） |
| 登录 | 浏览不用；部分版块/附件要登录 |

**建议操作**

- **必须用 `http://`**。这两个站 https 握手会失败，浏览器里也一样。地址栏看到 `https://` 直接改回 `http://`。
- 版面按发版时间看最新帖，别翻页翻太深——这类论坛的旧帖九成已失效。
- 帖子里常有短链和口令，**只记录不点击**，把原帖链接给用户即可。

**坑**

- https 失败不要误判成"站点挂了"，先换 http。
- 广告位和软文多，标题带"必撸""稳赚"的基本是引流，别当真。
- 部分帖子需要回复可见，但**本技能禁止回复/发帖**，看不到就如实说看不到。

## 四、V2EX 优惠信息（**已接入脚本，优先直连**）

| 项 | 内容 |
|---|---|
| 入口 | 网页 `https://www.v2ex.com/go/deals`；接口 `https://www.v2ex.com/api/topics/show.json?node_name=deals` |
| 通道 | **直连 API（推荐，实测 200 / 29KB）**，无需浏览器、无需登录 |
| 脚本 | `python3 scripts/v2ex_feed.py [--node deals] [--detail <id>]` |
| 登录 | 浏览不用 |

**建议操作**

- 适合捞"会员折扣、软件授权、云服务优惠、话费/红包、AI 额度"，不适合日用品。
- **先跑脚本拿列表**，再对命中门槛的条目 `--detail` 拉回复做失效判定，不要一上来就开浏览器。
- 正文和回复里常有人补"已失效/领完了"，**看前几条回复**比看正文更有用（`--detail` 已内置 `dead_markers` / `likely_dead`）。

**实测频率（2026-11-07）：这个节点更新很慢，别按 2 小时轮**

- 一次返回 10 条，最新一条在 49 小时前，10 条覆盖约 27 天。
- **一天扫一次足够**，塞进每日晨扫或晚间那一轮，不必进 2 小时循环。

**坑**

- 外链会跳到第三方，有些是 AFF 链接，报给用户时说明"含推广参数"。
- 帖子质量参差，纯提问帖占比高，别把提问当优惠。
- **API 有限流**（非官方约 120 次/小时）。403/429 时脚本抛 `Blocked`（退出码 2），别当"本轮没有羊毛"。
- 字段名是 `member.username`，不是 `member.name`；`last_touched` 偶有早于 `created` 的异常值，判新鲜度一律用 `created` / `age_hours`。
- 站点本身是 UTF-8，不存在乱码问题（会乱码的是爱Q生活网那类 GBK 站）。

## 五、LINUX DO 福利羊毛（AI 额度主战场）

| 项 | 内容 |
|---|---|
| 入口 | `https://linux.do/c/welfare/36`（福利羊毛板块） |
| 通道 | **必须真浏览器**，Cloudflare 会拦裸请求 |
| 登录 | 强烈建议登录，未登录可见内容少、且容易触发校验 |

**2026-11-07 补测：JSON 接口走不通，别浪费时间**

- `https://linux.do/c/welfare/36.json` 直连 **403**，返回 Cloudflare `Just a moment...`（7KB 挑战页）。
- 走本机代理一样 **403**，换 UA 无效。Cloudflare 认的是浏览器指纹，不是 IP。
- 结论：这个源**只能浏览器**，或者干脆等用户手动看一眼。不要为了它去写直连脚本。

**建议操作**

- 这是找 **AI 免费额度 / API credits / 试用名额** 质量最高的地方，B 段优先扫这里。
- 打开后先等 3–5 秒过 Cloudflare，再读 DOM；抢着读会拿到"请稍候…"。
- 用板块内的"最新"排序，不要用默认排序。
- 只收"能领的"（有链接、有兑换码、有限时说明），纯讨论贴一律不收。

**坑**

- **Cloudflare 拦截**：直连 403 "Just a moment"，文本长度只有几十字，就是被拦了。真浏览器一般能自动过，过不去就等或让用户手动点一下。
- 未登录时帖子列表可见但正文可能折叠，别把"看不到"当成"没有"。
- 帖子更新极快，2 小时一轮是合理频率，再密就是刷屏。

## 六、X（x.com）—— 羊毛与 AI 额度

| 项 | 内容 |
|---|---|
| 入口 | `https://x.com/home`（首页时间线）；建议自建 List |
| 通道 | **必须真浏览器 + 用户已登录账号**，且**必须走代理** |
| 登录 | 必需。登录由用户自己完成，技能不碰账号密码 |

**建议操作**

- 让用户提前关注一批羊毛线报号 / AI 官方号，或建一个 List。**扫 List 比扫首页稳定**——首页算法流噪声大，还会掺入大量无关推荐。
- 只浏览、只滚动，1–2 屏即止。不要点赞、不要转发、不要关注。
- 每条都要看**评论区**：高赞说"失效/已修复/领完了"的，一律不推。
- 判断"是不是新的"：看发布时间，超过 24 小时的领取类基本已经抢完，除非明确写着长期有效。

**坑**

- **不登录直接跳引导页**：`x.com/i/jf/onboarding/...`，正文只有一百来字，看到这个就是登录墙，别继续抓。
- **必须走代理**：国内直连不通。Chrome 启动时要显式给 `--proxy-server`，并让 `x.com` 不在 bypass 名单里。
- **限流**：短时间滚动太快会触发 "Something went wrong"，等几分钟再来，别反复刷新加重风控。
- 图片/视频懒加载，正文文本不受影响；但"图里才有兑换码"的帖子读不到码，要截图交给用户看。
- 登录 cookie 多为 session cookie，**关窗即失效**，登录成功后立刻 `python3 scripts/browser.py cookies --session deal-hunter-x --save <数据目录>/cookies/x.json` 备份；profile 本身也会持久化登录态，两者叠加最稳。

## 七、海外站（Slickdeals / DealMoon / CamelCamelCamel）

| 站点 | 用途 | 备注 |
|---|---|---|
| Slickdeals | 美区综合折扣，社区投票能看真假 | 走代理；正文极长（6 万+ 字），要按结构取而不是全文丢给模型 |
| DealMoon 北美省钱快报 | 华人海淘折扣 | 走代理；中文内容，适合国内用户 |
| CamelCamelCamel | 亚马逊历史价曲线 | 走代理；用来印证"亚马逊历史最低" |

**建议操作**

- 只在用户明确要海淘/海外时才扫，否则纯属浪费轮次。
- 这三个站都要代理，和国内站**不能共用同一个浏览器实例**（一个直连、一个走代理，混用必然有一个不通）。
- 用 `--proxy-bypass` 把国内域名列进去，一个实例也能兼顾，但**推荐直接开两个 session**，干净。

**坑**

- Cloudflare 站点（Camel、DealMoon）用裸请求会被拦，真浏览器能过。
- 亚马逊价格分"会员价/非会员价/ Coupon 后价"，Camel 曲线只反映其中一个口径，别直接下"历史最低"结论。

## 九、京东 / 淘宝 —— 只用于核价，不用于扫货

| 项 | 内容 |
|---|---|
| 用途 | 时效核验：确认价格还在、还有库存、券还能领 |
| 通道 | 浏览器 + 用户登录态 |
| 登录 | 基本必须 |

**建议操作**

- 登录后价格才准（有些券是会员专享）。

- 批量打开商品页极易触发验证，一轮最多核 3–5 个。

## 十、爱Q生活网（**已接入脚本，直连**）—— 银行立减金 / 话费 / 红包

| 项 | 内容 |
|---|---|
| 入口 | `https://www.iqnew.com/activity/`（活动分享，羊毛最多）；分页 `/activity/index_2.html` … `index_12.html` |
| 通道 | **直连 200**，无需浏览器、无需登录 |
| 脚本 | `python3 scripts/iqnew_feed.py [--page N] [--pages N]` |
| 更新 | 当天十几条，一页 25 条，**比 V2EX 勤得多** |

**捞的是什么**

银行立减金、话费充值优惠、红包抽奖、会员权益、话费券。跟 smzdm（商品降价）、V2EX（会员/AI 额度）三块互补，正好凑齐"领取类"羊毛。

**建议操作**

- 每轮 B 段先跑这个脚本（一页 25 条，一条请求），命中`亲测/红包/立减/免费/领取`等关键词的再进门槛判定。
- 只跑第 1 页就够：列表按日期倒序，第 2 页往后基本是隔天的，抢不到。
- **银行活动有周期性**（"每周三""每月"），看到这类记进周期表，别天天蹲。

**坑**

- **GBK 编码**。当 UTF-8 读全是乱码（实测第一次就栽在这）。脚本已按 GBK → GB18030 → UTF-8 顺序兜底。
- **首页和活动页结构不一样**：首页 `<li><a>标题</a><span>11-07</span>`（日期无年份、混着导航链接）；活动页 `<li><a title="标题"><span class="time">2026-11-07</span></a>`（完整日期）。**用 `/activity/`**，首页那套容易解析出错。
- 标题里的"亲测"是作者自述，不等于真到账；部分链接带返利参数，报给用户时要说明。
- 站点小、可能改版。一条都解析不出来时脚本抛 `Blocked`（退出码 2），不会静默返回空。

## 十一、通用规则（所有站点）

1. **时效核验是硬门槛**：看到"已过期/已售罄/售完/缺货/无货/活动结束/已抢光"任一，直接丢。
2. **链接归一化后再去重**：去掉 `utm_*`、`spm`、`from` 等跟踪参数；smzdm 取文章 ID。`ledger.py check` 已内置。
3. **落盘才算完成**：每个扫描页面都要留快照（`raw/日期/时间戳-站点-用途.json`）。
4. **登录一律由用户完成**：技能只负责把窗口切到前台，绝不代输账号密码、不代收验证码。
5. **抓不到就说抓不到**：不要用残留 DOM、缓存页、或"上次看到的价格"充数。
